# GitOps + Argo CD Tutorial Series

Companion repository for the **TechOps Tutorials** YouTube series on GitOps and Argo CD.

This repo contains configuration files, Kubernetes manifests, and hands-on examples used throughout the video series. Each episode has its own folder with the exact files used in that video.
